# ⚽ OlhaOGol

Jogo multiplayer de futebol onde você monta seu time com craques das Copas do Mundo e desafia seus amigos!

## 🎮 Como funciona

1. **Entre no site** - Sem cadastro, só digite seu nome
2. **Crie uma sala** - Receba um código para compartilhar
3. **Convide um amigo** - Seu amigo entra com o código
4. **Monte seu time** - Gire a roleta e escolha jogadores
5. **Enfrente seu amigo** - A simulação mostra o resultado
6. **Veja quem venceu** - Estatísticas e gols da partida

## 🏆 Copas disponíveis

- 1950 a 2026
- Mais de 70 seleções
- Mais de 800 jogadores com GER

## 🛠️ Tecnologias

- **Frontend:** React + Vite
- **Backend:** Node.js + Socket.IO
- **Multiplayer:** WebSocket em tempo real

## 🚀 Deploy

- Frontend: Vercel / Netlify
- Backend: Render / Heroku
